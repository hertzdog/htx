The test · October 2025

The same question, three answers. Only one is right.

A real database of a healthcare facility. We gave Gemini 2.5 Pro and ChatGPT-5 the database structure and the same question we asked MANTA:

“What is the production value of the visits carried out in 2004, by service, procedure and price-list group?” (asked in Italian)

Gemini 2.5 Pro Wrong
SELECT servizio, prestazione, gruppo_listino,
       SUM(valore) AS valore_produzione
FROM dbo.v_produzione
WHERE anno_accettazione = 2004
GROUP BY servizio, prestazione, gruppo_listino
ChatGPT-5 Wrong
SELECT servizio, prestazione, gruppo_listino,
       SUM(valore) AS valore_produzione
FROM dbo.v_produzione
WHERE anno_accettazione = 2004
GROUP BY servizio, prestazione, gruppo_listino
ORDER BY servizio, prestazione, gruppo_listino;
MANTA Correct
SELECT servizio, prestazione, gruppo_listino,
       SUM(valore) AS valore_produzione
FROM dbo.v_produzione
WHERE anno_accettazione = 2004
  AND prestazione LIKE '%visit%'
GROUP BY servizio, prestazione, gruppo_listino

Gemini and ChatGPT add up all of 2004's production: they forget that the question only asked about visits. The number they return looks plausible, and that is exactly what makes the error dangerous. MANTA adds the filter.

On a second database, from a clinic, it went the same way. In all, 11 questions, from the simplest to comparisons between half-years: 11 correct queries. In one case, all it took was specifying which date to use as the reference.

Frequently asked questions

Before trying it, people usually ask us:

What is MANTA?

An AI agent that turns a question in plain language into a query on your database, checks it, runs it and shows you the answer together with the query that produced it.

Why isn't it enough to load the database schema into ChatGPT or Gemini?

Because a general-purpose model doesn't know what your data means. In our tests on real databases, Gemini 2.5 Pro and ChatGPT-5 produced queries that looked plausible but were wrong. MANTA uses the description of the tables and a few reference questions prepared with you, and checks the query before answering.

Which databases does it support?

PostgreSQL, SQL Server, MariaDB, BigQuery, Snowflake, Databricks, AWS Athena and ClickHouse. For other databases, we check before we start.

Does our data leave the company?

No, if the models run on PRISMA, on your servers or in an EU cloud: neither the data nor the database structure ends up in public AI services. If you prefer a public model for a specific use, the choice is yours and we write it into the contract.

How do you stop a query from doing damage?

Every generated query is checked before it runs, to block harmful commands and unintended access. We define database access with you, with the minimum permissions needed.

Where has it already been used?

In tests on databases of healthcare facilities and with the ChemoMaker robot for drug preparation, together with Biovalley Investments and Trieste Valley.
